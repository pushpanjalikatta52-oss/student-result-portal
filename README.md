# 🎓 Student Registration & Result Portal

The **Student Registration & Result Portal** is a simple and responsive web application developed using **HTML5, Bootstrap, and JavaScript**. It allows students to enter their personal details, select a course, enter subject marks, and automatically calculate total marks, percentage, and Pass/Fail status.

## 🚀 Live Demo

👉 **[View Student Registration & Result Portal](http://127.0.0.1:5501/index.html)**

> Note: This `127.0.0.1` link works only on your computer while the project is running locally. For a public GitHub demo, use GitHub Pages.

## ✨ Features

* Student registration form
* Course selection
* Subject mark entry
* Automatic total calculation
* Percentage calculation
* Automatic Pass/Fail result
* Form validation
* Dynamic result display
* Responsive Bootstrap design

## 🛠️ Technologies Used

* **HTML5** – Webpage structure and forms
* **Bootstrap 5** – Responsive design and styling
* **JavaScript** – Validation, calculations, and dynamic content
* **CSS3** – Custom styling

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in **VS Code**.
3. Open `index.html`.
4. Run it using **Live Server**.
5. Enter student details and marks.
6. Click **Calculate Result** to view the result.
